# 🌈 Marachi Onyewenjo — Personal Portfolio

A modern, responsive and highly animated personal portfolio website built to showcase my skills, projects, and journey as a web developer.

The portfolio combines **HTML, CSS, Bootstrap, and JavaScript** to create a colorful, interactive, and professional experience across desktop, tablet, and mobile devices.

---

## ✨ Features

* 🎨 Modern and vibrant UI
* 🌈 Colorful gradient effects
* ✨ Smooth animations and transitions
* ⌨️ Animated typing effect
* 🎠 Automatic project carousel
* 📱 Fully responsive design
* 💻 Developer-inspired hero section
* 🛠️ Skills showcase
* 🚀 Featured projects section
* 🔗 GitHub, LinkedIn and TikTok integration
* 📩 Contact section
* 🌊 Scroll reveal animations
* 📌 Fixed glass-style navigation bar

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd portfolio
```

### 3. Run the website

Open `index.html` directly in your browser.

You can also use the **Live Server** extension in VS Code for a better development experience.
